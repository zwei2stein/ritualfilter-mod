Basic Name Search

Description Syntax Examples
Simple Name Search
Searches for text in pawn names (case-insensitive). Matches any part of the full name.
text bel - Finds Belle, Mirabel
john - Finds John, Johnny, Yojohn
Underscore as Space
Use underscores to search for names with spaces without needing quotes.
text_with_underscores john_doe - Finds John Doe

Passion Filters

Description Syntax Examples
Has Passion
Filters for pawns that have any passion (minor or major) for the specified skill.
passion:skill
p:skill 		passion:mining - Miners with passion
p:artistic - Artistic pawns
No Passion
Filters for pawns that have no passion for the specified skill.
!passion:skill
!p:skill
-passion:skill
-p:skill 		!passion:cooking - No cooking passion
!p:melee - Not melee-focused

Trait Filters

Description Syntax Examples
Has Trait
Filters for pawns that have the specified trait. Search is exact match.
trait:traitname
t:traitname 		trait:tough - Tough pawns
t:brawler - Brawlers
No Trait
Filters for pawns that do not have the specified trait.
!trait:traitname
!t:traitname
-trait:traitname
-t:traitname 		!trait:pyromaniac - Not pyromaniacs
!t:nudist - Clothed pawns
Multi-word Traits
Use underscores to replace spaces in trait names with multiple words.
Required for traits like "Hard worker", "Night owl", etc.
 trait:trait_name trait:hard_worker
trait:night_owl

Age Filters

Description Syntax Examples
Older Than
Filters for pawns older than the specified age (in biological years).
age>number
a>number 		age>12 - Not children (13+)
a>18 - Adults only
Younger Than
Filters for pawns younger than the specified age (in biological years).
age<number
a<number 		age<4 - Babies and toddlers
a<13 - Children only

Health Condition Filters

Description Syntax Examples
Has Hediff
Filters for pawns that have a health condition matching the search term.
Search can be partial - matches any hediff containing the term.
 hediff:text
h:text 		hediff:pregnant - Pregnant pawns
h:scar - Has any scar
hediff:fracture - Broken bones
No Hediff
Filters for pawns that do not have a health condition matching the search term.
!hediff:text
!h:text
-hediff:text
-h:text 		!hediff:archotech_eye - No archotech eyes
!h:alcohol - Not drunk/addicted

Ability Filters

Description Syntax Examples
Has Ability
Filters for pawns that have an ability matching the search term.
Search can be partial - matches any ability containing the term.
 ability:text
ab:text 		ability: - Any ability at all
ab:psychic - Psychic abilities
ability:inspire - Inspire ability
No Ability
Filters for pawns that do not have an ability matching the search term.
!ability:text
!ab:text
-ability:text
-ab:text 		!ability: - No abilities at all
!ab:word_of - No Word of... abilities

Skill Level Filters

Description Syntax Examples
Skill Greater Than
Filters for pawns with a skill level higher than the specified value.
skill>number mining>10 - Miners level 11+
shooting>5 - Decent shooters
Skill Less Than
Filters for pawns with a skill level lower than the specified value.
skill<number cooking<5 - Bad cooks
melee<10 - Not great fighters

Combining Filters

Pro Tip: You can mix and match any filter types. For example: age>12 trait:tough passion:mining mining>8 finds tough adult miners with mining passion who have level 9+ mining skill.
Description Syntax Examples
Multiple Conditions
Chain multiple filters together. All conditions must be satisfied.
filter1 filter2 filter3... age>12 trait:tough
passion:cooking !trait:nudist
Complex Search
Combine different filter types for precise pawn selection.
type:value type:value... a>18 p:art ab: shooting>10
t:hard_worker !h:pregnant age>12
